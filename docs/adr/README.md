# Architecture Decision Records (ADRs)

Short, dated records of significant technical decisions and the evidence behind them.
Each ADR captures **context → decision → consequences** so a future reader (human or agent)
knows *why*, not just *what*. ADRs do not change [locked decisions](../master-plan.md); a
decision to *evaluate* something (gated by a verify-on-arrival bake-off) is itself a valid ADR.
